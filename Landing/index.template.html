The fine print

Short, plain-language version of the legal stuff — the full license is on GitHub.

No warranty. Tappy is provided "as is," with no warranty of any kind. You use it at your own risk — the author isn't liable for any damages, direct or indirect, arising from installing or using it.

Unsigned app. Tappy isn't notarized by Apple (no paid developer account behind this project), so macOS will flag it as from an unidentified developer on first launch. That's expected for an indie project like this — but it does mean you're trusting an unsigned binary when you open it.

Your keystrokes stay yours. Tappy needs Accessibility access to hear key presses system-wide so it can play a click sound. It only reads which key was pressed, in memory, to pick a sound — it never logs, stores, or transmits anything you type, to disk or over the network.
